# Health360-Healthcare-Analysis
Health360 is a healthcare data analytics project developed using Tableau Public. It explores patient demographics and health indicators to help identify patterns and understand potential healthcare risk factors. 

Tools Used:
Tableau Public
Healthcare dataset
Data visualization and exploratory analysis

Visualizations:
The project includes visualizations for:
Patient Age Distribution
Gender Distribution
Blood Pressure Analysis
Cholesterol Analysis
Exercise Analysis
